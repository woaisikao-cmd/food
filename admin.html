🧭 数据更新流程
  1. 在这里录入 / 编辑 / 删除店铺，数据自动暂存在本浏览器中，关掉页面也不会丢。
  2. 维护完点 「📤 导出 shops.js」，保存到电脑本地。
  3. 打开 GitHub 仓库，上传替换里面的 data/shops.js（网页端 Add file 拖拽上传即可）。
  4. 粉丝刷新前台页面，就能看到最新探店点位。
